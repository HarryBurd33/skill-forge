Freeze frozen-criteria.json, development-cases.json, this document, semantic assertion program and held-out manifest before candidate implementation. Read checks literally. Candidate is 1 only for actual installed REA original-fixture analysis with all C1 semantic facts AND exit 0/no unresolved cleanup. EPERM cleanup after valid normalized output is useful partial progress but scores 0. No system security workaround is authorized by these criteria.
