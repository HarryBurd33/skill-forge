# Changelog

## 0.3.0 — 2026-10-18

- Add conversation/project intake that preserves final corrections, reports source coverage, and keeps private context out of shared skills.
- Present an implementation spec and observable verification plan before building. Offer an optional review pause and preserve explicit review-first requests on resume.
- Automatically use useful available construction, resource and independent review/evaluation subagents with bounded tasks and clear ownership.
- Strengthen comprehensive adaptive interviewing, explicit implementation assumptions, and metadata-consistent version folders.
- Add Windows PowerShell/manual setup and other-LLM instructions, cross-platform helper fixes and Windows/Linux/macOS CI. Tested configurations and unavailable native hosts are reported separately.
- Preserve prior release evidence; record the new comparison and exact historical regression rechecks in the v0.3.0 evaluation report.

## 0.2.0 — 2026-10-17

- Ask how to deliver the generated skill: local Markdown, folder/ZIP, GitHub repository, or another destination; preserve settled choices and publication scope.
- Continue dependency-aware refinement through questions, examples and critique, while preserving draft-now, quick and resume controls.
- Add bundled Skill Finder: delegated research after refinement and before implementation, inspected provenance/licenses, an integration recommendation and truthful limited-tool fallbacks.
- Persist delivery, domain output, refinement and research state separately; include Finder in portable bundles and managed installations.
- Tighten focused questioning after a candidate bundled independent decisions. Evaluation results and retained failures are recorded in [the versioned report](evals/v0.2.0/REPORT.md).

## 0.1.0 — 2026-10-16

First usable release of the original Skill Forge builder.

- Create a skill, improve a supplied skill, and evaluate shared builder improvements.
- Adaptive interview depth, settled-decision tracking, pace overrides and plain-chat handoffs.
- Canonical portable instructions; Codex and Claude Code setup guides; generated prompt bundle.
- Private session records, fixed evidence gates, automatic adoption, managed-copy protection and rollback.
- Research, prompt-building, planning and existing-skill examples; predefined cases and execution reports.
- Searchable question records, contribution forms, source/license ledger and allowlisted packages.

Executed evidence and remaining gaps are recorded in [the release report](evals/REPORT.md). Native Claude Code execution and universal model compatibility are not claimed.
