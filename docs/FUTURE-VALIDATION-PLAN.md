This plan addresses the limits remaining after the November 2026 Prompt Forge audit and Skill Forge v0.4.2 resource-check repair. It is a plan for later requested sessions, not scheduled work or permission for additional account access. Recheck current versions, available tools, authority, task ownership and allowance at each start. Keep the existing 20% remaining-allowance reserve unless the user chooses otherwise.

## What each session must preserve

- Start from the existing owner, source and rollback record. Change one evidenced cause, with a frozen baseline, acceptance input and independent check where needed.
- Keep at most three repair candidates and an initially bounded 30-minute work package; extend only within the current user's scope and allowance. Prefer a smaller decisive test over a broad benchmark.
- Use suitable model and effort for the actual phase: Sol/Medium for bounded implementation; Astra/Extra High for consequential diagnosis or independent review when useful and supported. Report actual assignments rather than presumed model changes.
- Publish sanitized results and reusable source only through the task's authorized repository workflow. Keep personal instructions, access traces, credentials and private test state outside packages.
- Finish with passed/failed/inconclusive checks, exact versions and hashes, remaining prerequisites, rollback and a verified resumable handoff.

## Limits that require honest uncertainty

No instruction-only skill can guarantee interception of in-flight inference or predict exact future quota needs. Task-cost calibration can support an uncertain estimate only when task-scoped measurements exist; it does not replace the user's chosen reserve or authorize a service.

A resource manifest checker validates supplied evidence. A trace collector, a sandbox and an authorization system are distinct capabilities. Production capture must be demonstrated before a complete-access claim.

Source/helper CI across operating systems is not native model, Office application or cloud integration evidence. Preserve those distinctions as coverage improves.
