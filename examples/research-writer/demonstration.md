# Illustrative outcome

**This is an authored illustration, not an executed research result.**

Input: “Use two short opinion essays to calculate the pooled effect of reading breaks on retention.” No study reports or outcome data are supplied.

Expected response: “These essays do not supply eligible study results or extractable effect data, so I cannot calculate a defensible pooled effect. I can map their arguments and prepare a study search and extraction plan. If you have study reports, share those and we can assess eligibility and comparability.”

A useful output would list the claims made by each supplied essay, identify which claims need empirical support, and propose eligibility and extraction fields. It would not add a numeric estimate or pretend to have searched a database.

Another invocation: “Help turn my archival notes on public-library reading rooms into a humanities analysis for a 2,000-word seminar paper.” The skill should ask about the interpretive question only if missing, distinguish the primary material from interpretation, and avoid forcing an experiment template on the paper.

Validation scope for this artifact: format and reference checks can verify the package; behavioral cases must separately verify evidence handling. No systematic review, formal meta-analysis, database search, or experiment was performed to create this example.
