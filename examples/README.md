# Worked examples

These small, original examples show the artifacts Skill Forge can produce. They are intentionally public and contain fictional inputs. The briefs and demonstrations are authored illustrations, **not records of successful model runs**. See the evaluation reports for actual execution evidence.

| Example | Repeated task | Important decision |
| --- | --- | --- |
| [Research writer](research-writer/brief.md) | Develop a question into a defensible research deliverable | Match the claim and method to the available evidence |
| [Adaptive prompt builder](adaptive-prompt-builder/brief.md) | Turn an emerging idea into a reusable prompt | Establish the output artifact and its destination |
| [Adaptive planner](adaptive-planner/brief.md) | Build and revise a feasible schedule | Preserve firm commitments and surface overload |
| [Existing skill improvement](existing-skill/README.md) | Improve action-item extraction | Preserve unknown owners instead of inventing them |

The three example skill folders are independently usable; Skill Forge is not a runtime dependency. Copy a folder into the host's supported skill directory. Their SKILL.md files deliberately contain no host-specific tool syntax. Artifact export, browsing, calendar access, and saved state require suitable host tools; without them the skill returns copyable contents and a handoff.

Private preferences in a real session belong in private session records or the target skill's local configuration. The fictional sleep times below are example inputs, not shared defaults.
